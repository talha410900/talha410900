## Open source

**[agent-handrail](https://github.com/talha410900/agent-handrail)** · [npm](https://www.npmjs.com/package/agent-handrail) · MIT

Handrails for production LLM agents: one tool loop and structured-output API across Claude, OpenAI, Gemini and OpenRouter, with the parts that break in real use handled for you.

```bash
npm install agent-handrail zod
```

- Fallback chains across Claude, OpenAI, Gemini and OpenRouter
- Tools defined once in zod, validated both ways
- Structured output with automatic repair
- Human approval gates for risky actions
- Typed run events for traces and logs, plus a scripted fake model for offline tests
