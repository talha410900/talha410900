## About

Full-stack engineer with **7+ years** shipping production web applications — **20+ products** taken from MVP to scale across startups and studios. I build React and Next.js products end-to-end and integrate LLMs into features that hold up under real load: streaming, structured outputs, RAG, tool calling, MCP, and agents.

- **LLM integration** — OpenAI API, Google Gemini, Anthropic Claude, orchestrated with LangChain, LangGraph & LlamaIndex: RAG pipelines, MCP (Model Context Protocol) tools, AI agents, multi-model routing
- **Product engineering** — Next.js (App Router, SSR & streaming), React, TypeScript, Node.js — fast, accessible, SEO-ready interfaces
- **Automations** — n8n and custom pipelines wiring LLMs into CRMs, dashboards, webhooks, and scheduled jobs
- **Web3, when a product needs it** — wallet integration and on-chain flows on Solana & Thirdweb
